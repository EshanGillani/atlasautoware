Before you drive

The order that keeps sessions from being wasted:

  1. Run the hardware check — fix every FAIL before powering the motor.
  2. Put the car on a stand, wheels off the ground, for the first race at v_scale 0.3.
  3. Map the track (Launcher → Mapping), then generate a raceline (Raceline).
  4. Record a practice run and rebuild the speed profile from the grip you actually measured (Practice).
  5. Raise v_scale one step per clean lap. Never two steps.

Warnings are usually fine — a missing OAK-D only disables camera detection. Failures are not: a bad raceline or a dead lidar means the car will not know where it is.
